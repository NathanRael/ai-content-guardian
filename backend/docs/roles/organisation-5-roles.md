# Organisation conseillée des 5 rôles

Cette structure aide à organiser le projet autour de cinq responsabilités complémentaires.

1. [01-cadrage-parties-prenantes.md](./01-cadrage-parties-prenantes.md) — finalité, utilisateurs, personnes affectées, risques et usage métier.
2. [02-donnees-modele.md](./02-donnees-modele.md) — données, reproductibilité, modèles et artefacts.
3. [03-evaluation-biais.md](./03-evaluation-biais.md) — métriques, matrices de confusion, cas limites et biais.
4. [04-explicabilite-interface.md](./04-explicabilite-interface.md) — explications, interface, compréhension et accompagnement humain.
5. [05-gouvernance-documentation-qualite.md](./05-gouvernance-documentation-qualite.md) — gouvernance, RGPD, traçabilité, documentation et qualité.

Les rôles ne sont pas indépendants. Ils doivent travailler ensemble : le cadrage définit l'usage, les données et le modèle le rendent possible, l'évaluation le vérifie, l'interface le rend compréhensible, et la gouvernance garantit qu'il reste responsable.

Les discours de chaque section ont été réécrits en mode personnel pour refléter la contribution de la personne qui tient ce rôle dans le projet : "Dans ce projet, ma partie consistait à...".
